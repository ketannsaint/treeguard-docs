Support

One monitored address for questions, incidents, and data requests: support@apps.themoonknows.com.

Never send a credential Support will never ask for your Azure DevOps personal access token, Microsoft Entra client secret, Atlassian password, or any API token. Do not include one in an email, a screenshot, or a log excerpt. If you think a credential has been exposed, revoke it in Azure DevOps first and tell us afterwards.

For a pilot request

Include your Jira Cloud hostname, your Azure DevOps organisation type (Services or Server), the Jira project and Azure DevOps project you want to connect, roughly how many pairs you expect to link, and which fields matter most. The app is not yet generally available on the Marketplace, so pilot scope is agreed before access is provided.

For a support request

Include your Jira Cloud hostname, the Jira project key, the approximate time of the problem, the agreement state shown in the reconciliation view, and the Jira issue key and Azure DevOps work item ID of an affected pair. Redact any field content your support contact does not need.

Things you can check first

  • A pair shows "conflict". Both sides changed the same field to different values. Decide which is right, make that edit on one side, then press Replay.
  • A status was not written. The state is missing from your status map. Add it and replay.
  • A tag was not written to Jira. Jira labels cannot contain spaces. Rename the tag in Azure DevOps and replay.
  • Nothing syncs at all. Check the connection is enabled, then re-run the setup check. An expired personal access token is the most common cause.

Security reports

Send suspected vulnerabilities privately to security@apps.themoonknows.com. Include reproducible steps and impact, but do not access data that does not belong to you.
