Data Deletion

Remove private operation history without changing Jira labels.

Delete your operation history

  1. Open Jira settings -> Apps -> Verified Label Manager for Jira.
  2. Scroll to Recent operations.
  3. Select Delete my operation history.

This permanently removes the current administrator's operation journals, change chunks, and history summaries. It does not change Jira issue labels. Use Undo this operation before deleting history if you want labels restored.

Automatic expiry and uninstall

Every record the app writes carries a 180-day time to live. A Jira site administrator can uninstall the app through Atlassian administration. Forge retains hosted storage for 28 days after uninstall.

Request assistance

Contact support@apps.themoonknows.com and provide the Jira Cloud site hostname. Do not provide passwords or API tokens. The vendor may ask the site administrator to verify authority before acting on site data.

Never send passwords or API tokens with a data request.
