Privacy Policy

Operated by Leopold Saint. Privacy contact: support@apps.themoonknows.com.

Information processed

  • Jira project IDs and keys.
  • Template names, issue type IDs, patterns, labels, and versions.
  • Execution status, timestamps, Jira issue IDs/keys, and bounded errors.
  • The current Atlassian account ID during a request. The raw account ID is not stored; a project-scoped SHA-256 owner key isolates history.

Purpose and hosting

Information is used to store templates, create and verify Jira issue trees, recover interrupted operations, attempt cleanup, and show outcomes. Compute and storage are provided by Atlassian Forge. The app has no remote backend, external analytics, advertising, or AI service.

Retention and deletion

  • Execution receipts and indexes expire after 180 days.
  • Users can permanently delete their own project run history.
  • Project admins can delete templates, including while unlicensed.
  • Forge retains hosted storage for 28 days after uninstall. With customer consent, a recovery request must be submitted within 21 days.

Security and sharing

Jira requests run as the current user and protected actions check Jira permissions. The app does not collect credentials, sell personal information, or send End User Data outside Atlassian-hosted Forge and Jira services. All stored End User Data is treated as in-scope for data residency and follows the host Jira site's supported location and migration.

Contact

Send privacy, access, or deletion questions to support@apps.themoonknows.com. Include the Jira site and project key, but never include passwords or API tokens.

Material changes will update this policy's effective date.
