Privacy Policy

Verified Label Manager for Jira is operated by Leopold Saint. Privacy contact: support@apps.themoonknows.com.

Scope

This policy explains how Verified Label Manager for Jira processes information when installed in Jira Cloud. The app is built entirely on Atlassian Forge and has no remote backend, advertising, or external analytics.

Information processed

  • The JQL scope entered for an operation.
  • Source and target label names.
  • An operation journal containing the operation kind, scope, steps, status, and timestamps.
  • For selected issues, the Jira issue ID, issue key, and exact labels before and after the change.
  • The current Atlassian account ID during a request. The raw account ID is not stored; a SHA-256 owner key isolates each administrator's records.

Jira issue keys, labels, and JQL text may contain personal information chosen by the customer. The app does not read or store issue summaries, descriptions, comments, attachments, custom fields, or reporter and assignee identities.

Purpose and hosting

The app uses this information to preview a change, perform the approved Jira bulk edit, verify each issue, compensate an operation, resume interrupted work, and show an outcome or CSV export to the administrator who started it. Compute and storage are provided by Atlassian Forge. The app does not send customer data to vendor-hosted infrastructure or third-party analytics, advertising, or AI services.

Authorization and retention

Protected actions require Administer Jira and Make bulk changes. The server derives every operation identity from the caller, so one user cannot read, resume, undo, or export another user's operation. Queued work uses the immutable plan recorded when the administrator approved it.

  • Operation records expire 180 days after their latest write.
  • Administrators can delete their own operation history at any time.
  • Forge retains hosted storage for 28 days after uninstall.

Contact and security

Send privacy, access, or deletion questions to support@apps.themoonknows.com. Report suspected vulnerabilities to security@apps.themoonknows.com. Include the Jira site but never send passwords or API tokens.

Material changes will update this policy's effective date.
