Support

Help for controlled pilots, configuration, and data requests.

Role-based support contact Email support@apps.themoonknows.com. Do not send passwords, API tokens, private keys, or unrelated Jira content.

For a pilot request

Include the Jira Cloud hostname, the approximate issue count, the labels you need to change, whether a disposable project is available, and the verification or undo behavior that matters most. The app is not yet generally available on the Marketplace, so pilot scope must be agreed before access is provided.

For a support request

Include the Jira Cloud hostname, app environment, approximate time, operation status, and any issue keys shown in the receipt. Redact labels or JQL that contain information your support contact does not need.

Priority Example Initial response
Critical Security incident or widespread destructive behavior 1 business day
High App unavailable or unexpected label changes 1 business day
Normal Configuration, isolated error, or data request 2 business days
Low Feature request or documentation feedback 5 business days

Security reports

Send suspected vulnerabilities privately to security@apps.themoonknows.com. Include reproducible steps and impact, but do not access data that does not belong to you.

Support hours: Monday-Friday, 09:00-18:00 IST.
