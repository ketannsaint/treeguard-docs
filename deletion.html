User controls

Data Deletion

Remove private execution history or shared project templates.

Delete your run history

  1. Open Verified Issue Trees in the relevant Jira project.
  2. Open Run history.
  3. Select Delete my run history.
  4. Confirm Delete history.

This removes only your receipts and indexes for that project. It does not delete shared templates or Jira issues. The control remains available while the app license is inactive.

Delete shared templates

A Jira project administrator can delete an individual template while licensed. When unlicensed, the administrator can select Delete all project templates. Neither action deletes previously created Jira issues.

Uninstall and assistance

Site administrators can uninstall the app through Atlassian administration. Atlassian controls Forge data handling after uninstall. For help, contact leo.saint.dior@gmail.com with the site hostname and project key.

Never send passwords or API tokens with a data request.
