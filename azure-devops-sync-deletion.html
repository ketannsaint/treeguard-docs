Data deletion

How to remove everything Azure DevOps Sync for Jira holds, and what happens to each kind of record.

Deleting app data never deletes your work Removing a connection, or uninstalling the app, deletes only the app's own records. Your Jira issues and your Azure DevOps work items are left exactly as they are. This app never deletes either of them.

Delete one linked pair

Open the issue, use the Azure DevOps panel, and choose Unlink. The link record and both of its lookup entries are removed immediately. The issue and the work item are untouched, and neither is changed again after that.

Stop all syncing without deleting

In Project settings, open Azure DevOps Sync and choose Pause sync. The app deletes the service hooks it created in your Azure DevOps project and discards the webhook credentials it generated. Nothing is synchronised until you turn it back on.

Delete everything for a project

Pause sync, then uninstall the app. Atlassian removes the app's Forge storage, which includes the connection settings, all link records, the event journal, and the encrypted credentials.

What is deleted, and when

Record Removed
Link record for one pair Immediately when you unlink that issue
Azure DevOps service hooks and webhook credentials Immediately when you pause sync
Event journal entries 90 days after their last write, automatically
Connection settings, all link records, and stored credentials On uninstall. Atlassian retains Forge hosted storage for 28 days afterwards, then deletes it.

Revoke the credential yourself

The app cannot revoke an Azure DevOps personal access token or a Microsoft Entra client secret on your behalf, and uninstalling does not revoke it either. Revoke it in Azure DevOps or in your Entra tenant. Do this first if you believe a credential has been exposed.

Ask for a deletion in writing

Email support@apps.themoonknows.com with your Jira Cloud hostname and the Jira project key. Requests are answered within two business days. Never include an API token in the request.
